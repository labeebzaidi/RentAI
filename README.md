## 📌 Overview

RentAI is an AI-powered web application that predicts house rent based on property details such as:

- 🛏️ BHK
- 📐 Area (sqft)
- 🛁 Bathrooms
- 🏢 Property Type
- 👤 Seller Type
- 🛋️ Furnishing Status
- 📍 Location

The application uses a trained **Random Forest Regression Model** to estimate rental prices instantly.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/labeebzaidi/RentAI.git
```

Move into the project:

```bash
cd RentAI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
